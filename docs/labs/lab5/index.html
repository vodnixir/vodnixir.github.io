    Лабораторная работа 5. Машинное обучение: предсказание цен на недвижимость

    Описание задачи

    Цель лабораторной работы — изучить основы построения регрессионных моделей машинного обучения на реальных данных. В качестве задачи выбрано прогнозирование стоимости домов в округе Кинг (штат Вашингтон, США) по 15 характеристикам объектов недвижимости.

    В ходе работы требовалось:

    • загрузить и исследовать набор данных из Excel-таблицы;
    • обработать данные перед обучением;
    • обучить модели линейной регрессии и случайного леса;
    • провалидировать модели на тестовой выборке;
    • выявить наиболее значимые признаки;
    • в самостоятельной части — удалить незначимые признаки, настроить гиперпараметры и сравнить с альтернативными моделями (GradientBoosting, XGBoost, LightGBM).

    Исходные данные

    Набор данных содержал 21 613 записей о продажах домов (май 2014 — май 2015), разбитых на обучающую (15 129 объектов) и тестовую (6 484 объекта) выборки. Каждый объект описывается 15 входными признаками и целевой переменной — ценой продажи.

    Признаки: число спален и ванных комнат, жилая и общая площадь, количество этажей, наличие вида на воду, оценка состояния риелтором, площадь без подвала и подвала, год постройки, год реновации, координаты (широта, долгота).

    Как была решена задача

    Использованные библиотеки: pandas, numpy, matplotlib, scikit-learn, xgboost, lightgbm.

    1. Загрузка и анализ данных

    Данные считывались функцией pd.read_excel(). После загрузки проверялась структура таблицы (метод .info()), наличие пропусков и типы столбцов. Пропусков в данных не оказалось, однако столбец «Год реновации» содержал 14 490 нулей из 15 129 строк — это закодированные пропуски, а не реальный год.

    Целевая переменная («Целевая.Цена») отделялась от входных признаков методом .drop(axis=1).

    2. Обучение базовых моделей

    Сначала были обучены две модели из библиотеки sklearn:

    • Линейная регрессия (LinearRegression) — простая и интерпретируемая модель, предполагающая линейную зависимость цены от признаков;
    • Случайный лес (RandomForestRegressor) — ансамблевая модель на основе деревьев решений, способная улавливать нелинейные зависимости.

    Обе модели обучались методом .fit(training_points, training_values).

    3. Валидация на тестовой выборке

    Для оценки качества использовались:

    • MAE (средняя абсолютная ошибка);
    • RMSE (корень из среднеквадратичной ошибки).
    Модель MAE RMSE
    Линейная регрессия 126 852 201 883
    Random Forest (по умолчанию) 70 874 135 314

    Случайный лес оказался значительно точнее. Это также подтвердилось визуально: на scatter-графике «настоящая цена — предсказанная цена» точки модели случайного леса располагались значительно ближе к диагонали.

    4. Анализ важности признаков

    Поле feature_importances_ обученного RandomForestRegressor позволило ранжировать признаки по вкладу в предсказание:

    Наиболее важные:

    1. Оценка риелтора — ~0.30
    2. Жилая площадь — ~0.30
    3. Широта — ~0.17
    4. Долгота — ~0.07
    5. Год постройки — ~0.03

    Наименее важные:

    1. Год реновации — ~0.002
    2. Количество этажей — ~0.003
    3. Состояние — ~0.004
    4. Спальни — ~0.004
    5. Площадь подвала — ~0.007

    Появление широты в топе объясняется географически: центр Сиэтла расположен в верхней части округа Кинг, и объекты ближе к нему стоят дороже.

    Самостоятельная часть

    1. Удаление незначимых признаков

    Пять наименее важных признаков (Год реновации, Количество этажей, Состояние, Спальни, Площадь подвала) были удалены, и Random Forest переобучен на оставшихся 10 признаках.

    Модель MAE RMSE
    Random Forest (15 признаков) 70 874 135 314
    Random Forest (10 признаков) 71 153 135 232

    Качество почти не изменилось: незначимые признаки и без явного удаления почти не используются деревьями. Главный плюс — модель обучается и предсказывает быстрее.

    2. Тюнинг гиперпараметров Random Forest

    Перебор конфигураций через RandomizedSearchCV (20 итераций, 3-fold CV) дал лучшие параметры: n_estimators=500, max_depth=50, min_samples_split=10, min_samples_leaf=2, max_features=1.0.

    Модель MAE RMSE
    Random Forest (по умолчанию) 70 874 135 314
    Random Forest (подобранные параметры) 70 657 135 351

    3. Сравнение с другими моделями

    Были протестированы три дополнительные модели на основе градиентного бустинга:

    Модель MAE RMSE
    GradientBoosting (sklearn) 67 811 126 067
    XGBoost 64 618 117 390
    LightGBM — лучший результат

    XGBoost и LightGBM уверенно превзошли Random Forest по всем метрикам. Эти модели лучше обрабатывают нелинейные зависимости и при правильной настройке дают минимальную ошибку на задачах регрессии с табличными данными.

    Нюансы решения

    Закодированные пропуски

    Столбец «Год реновации» не содержал явных NaN, но 96% значений были равны нулю. При слепом использовании таких данных модель получает искажённый сигнал — как будто большинство домов отремонтированы в «год 0». Правильная обработка — либо удалить признак, либо создать бинарный флаг «был ли ремонт».

    Разница между линейной и нелинейной моделью

    Линейная регрессия предполагает, что цена — это взвешенная сумма признаков. Для дорогих объектов это грубое приближение: модель систематически занижала прогноз для домов стоимостью выше 2 млн долларов. Random Forest улавливает нелинейные зависимости и взаимодействия между признаками, поэтому ошибка почти вдвое меньше.

    RandomizedSearchCV вместо GridSearchCV

    При большом пространстве гиперпараметров полный перебор (GridSearchCV) занимает непрактично много времени. RandomizedSearchCV случайно выбирает n_iter конфигураций и в большинстве случаев находит решение, близкое к оптимальному, за долю времени.

    Почему бустинг лучше Random Forest

    Random Forest строит деревья независимо и усредняет их предсказания. Бустинг строит каждое следующее дерево на ошибках предыдущего, последовательно уточняя результат. На большинстве табличных датасетов это даёт более точную модель при сравнимом количестве деревьев.

    Интеграция модели с веб-сервисом

    В качестве бонусного задания был разработан план интеграции лучшей обученной модели с HTTP-сервисом на Flask:

    1. Сохранить модель на диск через joblib.dump().
    2. Написать Flask-приложение с эндпоинтом POST /predict, принимающим JSON с признаками объекта.
    3. Внутри эндпоинта — загрузить модель, сформировать DataFrame с нужным порядком столбцов и вернуть предсказание.
    4. Для продакшена — запускать через gunicorn, упаковать в Docker-контейнер, добавить валидацию входных данных через pydantic.

    Выводы

    В ходе работы были изучены полный цикл построения регрессионной модели: от загрузки и проверки данных до сравнения нескольких алгоритмов и анализа важности признаков. Лучший результат показал LightGBM — градиентный бустинг с RMSE значительно ниже, чем у базового Random Forest. Ключевые признаки для прогноза цены — оценка риелтора, жилая площадь и географические координаты объекта.
